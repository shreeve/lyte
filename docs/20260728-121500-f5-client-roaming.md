# F-5 (client half): the session survives the host moving out from under it

2026-07-28. The motivating pain is recent and real: the owner traveled,
the hotel network re-addressed the host, and the client experience was
"No hosts found" plus a frozen frame with no recovery story. This
record covers the CLIENT half of F-5 — detection, re-acquisition, UX,
and client-side path changes. The host half (session-busy/takeover:
freeing a dead session faster than the 30 s liveness clock when the
same identity re-dials) is Host territory and lands separately.

## The one idea

**The host's Noise static key is its identity; the address is a dial
hint.** The advertisement carries `pkh` (sha256 of the static) in its
TXT record; the pinned-host store keys by the same hash; pairing
therefore survives any address change by construction. Roaming is
nothing more than: notice the silence, hunt the identity, dial where
it lives now, run a fresh 1-RTT Noise IK against the same pinned
static. Same pairing, no re-PIN, ever.

## The detection ladder (RoamingPolicy, sans-IO, virtual-time)

Tiered on top of the session machine's own semantics (W4b: FROZEN and
RECOVERY are local overlays, never wire states; 30 s of no
authenticated evidence closes the session):

| tier | trigger | response |
|---|---|---|
| blip | FROZEN (350 ms tightened / 2.5 s beacon-bounded) | the CL-8 pill; the policy only starts its silence clock |
| story | 3 s of continuous silence | QUIET discovery re-browse begins (multicast is cheap; the session still stands; evidence returning cancels everything) |
| host moved | same `pkh` sighted at a NEW address | the standing session is unreachable by construction — tear down, dial immediately |
| host dark | same `pkh` at the SAME address, silence ≥ 8 s | the path works but the session is dark (host restarted / our source moved without HS-12 carrying): re-dial — early enough to beat the 30 s close, late enough that a Wi-Fi roam never triggers it |
| gone | the liveness close | full roaming: scans on a backoff ladder, blind probe dials of the last-known address between them (mDNS-less routed networks have nothing to sight — the dial hint is the only target) |

**Client-side path change** (the Mac hops Wi-Fi; the host stays put):
`NWPathMonitor` reduced to an interface-set/satisfiability signature —
the baseline observation never fires, any later change does. HS-12's
PathValidator on the host owns migration (the client's feedback
cadence keeps sending from the new source unprompted), so a path
change grants a 3 s GRACE — deliberately past the 2.5 s untightened
detector, so a dead path is observably FROZEN at expiry — before the
same scan/dial ladder runs, with the same-address redial threshold
waived (our own address moved; a fresh handshake IS the mechanism when
migration didn't carry). If the path healed itself, the deadline
dissolves.

**Give-up posture: there isn't one.** Fruitless scans back off 1 s
doubling to a 15 s ceiling; dial retries 2 s doubling to 30 s; every
deadline strictly in the future — passive looking, never hot, forever.
The human's Disconnect is the exit. The manual **Reconnect** verb
(Actions menu, ⌘R) resets every ladder and acts now: typed goodbye,
immediate probe dial plus a scan.

The policy is a struct in the SessionStateMachine discipline: inputs
applied under an injected monotonic `now`, decisions returned as
actions (`beginScan` / `dial`), `nextDeadline` tells the driver when
to tick. The whole ladder pins in virtual time.

## The re-acquisition flow (ConnectionModel as driver)

- `detachWireSession` — roaming-preserving teardown: the wire session
  goes away (typed 0x0A goodbye when there's anybody to hear it), the
  stream window and everything per-HOST stays: the live clipboard
  consent, the confirmed host-audio posture, the input capture (sends
  route through `lyteSession` live — they drop while nil, resume when
  it returns; no reinstall), and the bulk coordinator (F-4's
  `sessionEnded`/`sessionReady` resume path — the same id re-offers,
  which is exactly what makes a mid-transfer roam finish sha-exact).
  A `sessionEpoch` counter kills stale events from detached sessions.
- `runRoamingDial` — fresh `NoiseTransportCrypto` against the pinned
  static (3 attempts × 700 ms — shorter than a first connect: a host
  that hasn't freed the dead session answers with silence; the ladder
  retries, don't camp), live posture in the session config (confirmed
  audio posture, live clipboard consent).
- `adoptReconnectedSession` — swap the session in, refresh the pinned
  dial hints (identity-keyed `pin` keeps pairedAt + preferences), let
  capability agreement drive the rest exactly like a first connect.
  A dial that lands after the human disconnected is closed politely.

## UX

- The stream overlay's pill is now tiered: FROZEN blip keeps the CL-8
  "Connection interrupted…" pill; past the thresholds the banner SAYS
  what is happening — "Connection lost — looking for pup…", "pup found
  at 10.9.9.9 — reconnecting…", "Reconnecting to pup at …" (blind
  probe).
- Actions menu: **Reconnect** (⌘R), enabled for the window's whole
  streaming life; **Disconnect** stays enabled during a hunt (the
  session object is gone but the window still hunts).
